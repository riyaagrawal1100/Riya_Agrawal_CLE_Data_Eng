# CLE Data Engineering

This repository documents my learning journey through the **Celebal Learning Engagement (CLE) — Data Engineering Program**. It contains weekly hands-on labs, assignments, code, and documentation developed throughout the program.

## Program Overview

The program focuses on building practical data engineering skills, from understanding data workflows to developing reliable, analytics-ready data pipelines.

Key areas of learning include:

- **SQL & Databases:** Querying, data profiling, joins, aggregations, and analytical data modeling.
- **Python for Data Engineering:** Data ingestion, transformation, validation, and error handling.
- **ETL/ELT & Pipelines:** Batch processing, incremental loading, and workflow orchestration.
- **Data Processing:** Spark, PySpark, and distributed data processing.
- **Cloud Data Engineering:** Exposure to Azure data services and modern data platforms.
- **Data Quality & Delivery:** Validation, logging, version control, documentation, and testing.
