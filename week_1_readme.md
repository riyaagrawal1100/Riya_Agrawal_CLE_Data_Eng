# Week 1: SQL Analytics and Data Profiling

## Objective
Perform data profiling and business analysis using MySQL.

## Tools
- MySQL 8.0
- MySQL Workbench
- VS Code

## Tasks Completed
- Checked row counts, missing values, and duplicate records.
- Identified invalid quantities.
- Analyzed daily revenue, top products, repeat customers, order status, and average order value.
- Used a CTE and window functions (`RANK()` and `ROW_NUMBER()`).

## Dataset
Customers, products, orders, order items, and events CSV files.
